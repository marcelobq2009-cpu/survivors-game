# Survivors Game (protótipo)

Base de um jogo survivors-like em **Godot 4.7.2** (GDScript), feito para celular em retrato.
Tema ainda a definir — arte placeholder geométrica.

**Jogar no navegador/celular:** https://marcelobq2009-cpu.github.io/survivors-game/

- Rodar no PC (Windows): `.\scripts\run.ps1` · Testes: `.\scripts\test.ps1` · Build web: `.\scripts\build-web.ps1`
- Linux/CI: mesmos scripts com `.sh` (`./scripts/setup-godot.sh` baixa o Godot).
- Documentação: [`docs/`](docs/) · Guia para o Claude: [`CLAUDE.md`](CLAUDE.md)
